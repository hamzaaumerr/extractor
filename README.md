# 🧑‍🏫 Professor Info Extractor

**Professor Info Extractor** is an AI-powered web scraping tool designed to extract academic profiles from professors' personal web pages. Using the Gemini API and a list of URLs provided in a CSV file, this app extracts valuable information and compiles it into a downloadable CSV.

---

## 📌 Overview

This application allows users to upload a CSV file containing URLs of professors’ personal academic pages. With the help of **Gemini API**, the app visits each URL and intelligently extracts the following details:

- 👨‍🏫 Professor Name  
- 📧 Email Address  
- 🏛️ Department  
- 🧪 Research Field  
- 💡 Research Interests  

After processing all entries, the app provides a **downloadable CSV** containing all the extracted data in a structured format.

---

## ⚙️ Features

- 🔍 **Automated Data Extraction**  
  Scrapes and extracts structured professor info using AI.

- 📂 **CSV Upload**  
  Upload a list of URLs and let the app do the rest.

- 🤖 **Gemini API Integration**  
  Leverages Google Gemini for accurate text understanding.

- 📄 **Downloadable Output**  
  Export all extracted data into a clean, ready-to-use CSV file.

- 🧼 **Clean & Simple UI**  
  Built with Streamlit for an easy-to-use interface.
